# بوت تيليجرام لتنزيل فيديوهات TikTok

بوت Python بسيط يستقبل رابط TikTok عامًا، ثم يحاول تنزيل أفضل ملف MP4 متاح وإرساله للمستخدم.

> استخدمه فقط لتنزيل الفيديوهات التي تملكها أو لديك إذن من صاحبها. توفّر نسخة بلا علامة مائية يعتمد على الملف الذي يتيحه TikTok، لذلك لا يمكن ضمان ذلك لكل فيديو.

## 1) إنشاء البوت

1. افتح تيليجرام وابحث عن الحساب الرسمي `@BotFather`.
2. أرسل `/newbot` واتبع التعليمات.
3. انسخ الرمز السري الذي يعطيك إياه. لا ترسله لأي شخص ولا تضعه في منشور عام.

## 2) التثبيت على الكمبيوتر

ثبّت Python 3.11 أو أحدث، ثم افتح الطرفية داخل مجلد المشروع ونفّذ:

```bash
python -m venv .venv
```

على Windows:

```powershell
.venv\Scripts\activate
```

على macOS أو Linux:

```bash
source .venv/bin/activate
```

ثم ثبّت المتطلبات:

```bash
pip install -r requirements.txt
```

## 3) إضافة رمز البوت

انسخ الملف `.env.example` وسمِّ النسخة `.env`، ثم ضع الرمز هكذا:

```env
TELEGRAM_BOT_TOKEN=123456789:ضع_الرمز_الحقيقي_هنا
```

## 4) التشغيل

```bash
python bot.py
```

افتح البوت في تيليجرام، أرسل `/start`، ثم أرسل رابط فيديو TikTok عام.

## حل المشكلات

- إذا توقف التنزيل بعد تغييرات TikTok، حدّث الأداة: `pip install -U yt-dlp`.
- حسب Telegram Bot API، الإرسال المباشر عبر البوت محدود حاليًا بنحو 50 MB؛ لذلك يرفض المشروع الملفات الأكبر قليلًا من ذلك.
- الروابط الخاصة أو المحذوفة أو المقيّدة قد لا تعمل.
- أبقِ نافذة الطرفية مفتوحة ليستمر البوت. للتشغيل الدائم ستحتاج إلى استضافة تدعم Python.
